dls-check

Is your codebase ready for Saudi DGA compliance?

Saudi's Digital Government Authority mandates one design system for every ministry — RTL-first, IBM Plex Sans Arabic, WCAG 2.1 AA — and it's a legal requirement. dls-check scans your code for the gaps and prints the manual checklist for the rest.

$ npx dls-check .
View on GitHub → More Otto tools

What it checks

  • RTL-first — physical CSS/Tailwind + hard-coded dir="ltr" that breaks the DGA default
  • Font — flags stacks missing IBM Plex Sans Arabic (DGA-mandated)
  • WCAG 2.1 AA — missing alt, missing <html lang>
  • + a manual checklist — official DGA tokens/components, contrast, keyboard nav, AR⇄EN parity
